사용 허용 계정

관리자 외에 이 웹앱을 쓸 Google 계정
관리자 — 계정 등록·삭제 권한
계정마다 독립 작업 공간 — 각자 자기 드라이브의 원본시트를 연결해 자기 DB를 만들고, 서로의 파일은 공유되지 않음. 관리자에게는 각 계정의 연결·최근 실행 요약만 표시됨. 추가된 사용자는 첫 접속 때 Google 권한 승인(확인되지 않은 앱 → 고급 → 이동)이 한 번 필요함. 목록에서 삭제하면 웹앱 접근이 즉시 차단되고, 그 계정의 자동 갱신도 다음 실행 시점에 스스로 해제됨.
